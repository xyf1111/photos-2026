首次使用 · 填一次就好

粘贴你的 GitHub Token（只存在本机，之后永久记住，不用再填）。分类、仓库都内置好了。

Token 怎么弄？

github.com → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token；只选 photos-2026 这一个仓库，权限勾 Contents: Read and write。有效期选 7 天或 90 天都行。
